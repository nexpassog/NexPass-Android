## Default Permission

Default permissions for the nexpass-autofill plugin

#### This default permission set includes the following:

- `allow-open-autofill-settings`
- `allow-autofill-status`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>

`nexpass-autofill:allow-autofill-status`

</td>

</td>
</tr>
